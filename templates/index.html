What happens behind your plan

Every request travels through a small team of specialists, so no single model has to guess at everything.

  • Flight agent

    Checks live flight information through AviationStack.

  • Hotel and sightseeing agent

    Searches the web with Tavily for stays and attractions that match your budget.

  • Itinerary agent

    Uses Groq-hosted models to turn the findings into a clear day-by-day plan.

  • Memory

    Saves your conversation in PostgreSQL, so follow-up questions build on the same trip.
